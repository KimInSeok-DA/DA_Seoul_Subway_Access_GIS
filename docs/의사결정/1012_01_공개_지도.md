# 1012_01 공개 지도(GitHub Pages)

## 왜

ArcGIS Location Platform은 Hosted Feature Layer의 공개 공유를 지원하지 않는다(1011_05). 로그인 없이 결과를 볼 수 있는 링크가 하나 필요하다.

## 선택지

| 안 | 장점 | 단점 |
|---|---|---|
| **Leaflet 정적 지도 + GitHub Pages (채택)** | 키·비용 없음, 계정과 무관하게 링크 유지, 코드가 짧아 설명하기 쉬움 | ArcGIS 레이어를 직접 쓰지 않음(같은 결과 파일을 씀) |
| ArcGIS Maps SDK for JavaScript + 제한 API 키 | ArcGIS 레이어·웹맵을 그대로 씀 | 브라우저 코드에 키 노출(주소·권한 제한 필요) |

## 구성

- `src/build_web.py`: `data/processed/`의 결과로 `docs/map/data.js`를 만든다. 경계를 EPSG:5179에서 5m 허용오차로 단순화(`preserve_topology`), 좌표 소수 5자리. 5.1MB → 0.75MB. 단순화 후에도 467개 모두 유효한 도형인지 확인하고, 아니면 멈춘다. 지표는 원본 경계로 이미 계산된 값을 그대로 쓴다
- `run.py`: 검증을 통과했을 때만 `build_web`을 돌린다(공개 지도도 검증 실패 시 갱신하지 않음)
- `docs/index.html`, `docs/map/app.js`, `docs/map/style.css`: Leaflet 1.9.4(cdnjs). 지표 3개 전환(거리·500m 면적 비율·역 수), 범례, 역 표시 켜기·끄기, 한글 팝업, 출처·이용 조건 표시
- 구간은 ArcGIS 웹맵과 같다: 거리 300/500/800/1,200m(경계값은 아래 구간에 포함)
- GitHub Pages는 `main` 브랜치 `/docs` 폴더에서 배포. `docs/.nojekyll`로 Jekyll 변환을 끈다(문서 .md는 그대로 둠)

## 배경지도

- 처음 CARTO Positron을 썼으나 헤드리스 브라우저로 띄워 보니 타일에 "API KEY REQUIRED"가 찍힘 → 키가 필요 없는 OpenStreetMap 기본 타일로 바꾸고, 단계구분도가 잘 보이도록 CSS로 흑백 처리
- OpenStreetMap 타일 이용 정책에 따라 출처(© OpenStreetMap 기여자)를 표시한다

## 확인 (실제 실행)

- Edge 헤드리스(GPU 끔)로 1400×900, 500×900 화면을 캡처해 단계구분도·역 점·범례·출처가 그려지는 것 확인
- 좁은 화면에서 패널과 지도가 위아래로 나뉘고 글자가 잘리지 않음. 축소 시 역 점이 겹쳐 확대 수준에 따라 점 크기를 바꿈

## 재검증 후 변경 (단순화 5m → 1m)

- 재검증에서 지도에 그린 경계와 원본의 동별 면적을 비교하니 5m 단순화는 최대 3.91%(동소문동3가 0.028㎢ 등 작은 도심 동 26개가 1% 초과), 최대 어긋남 9.0m
- 허용오차별 비교(실제 실행): 1m → 최대 0.50%·1.6m·경계 1.05MB / 2m → 1.33% / 3m → 2.13% / 5m → 3.91%
- **1m로 변경**. `data.js` 0.75MB → 1.22MB. `build_web.py`가 동별 면적 차이 1%를 넘으면 멈추게 했고, 5m로 돌리면 `3.91% > 1.0%`로 멈추는 것을 확인
- 지표 값은 처음부터 원본 경계로 계산해 바뀌지 않음(공개 지도 값 467개 = 지표 결과)

## 바꾸는 조건

- OpenStreetMap 타일이 막히거나 느리면 다른 무키 타일로 바꾼다
- 시간이 남으면 ArcGIS JS 앱을 추가한다(이 지도는 그대로 둠)
