# 1012_02 다중 포맷 내보내기

## 결정

| 포맷 | 이유 | 처리 |
|---|---|---|
| GeoPackage | OGC 표준, 레이어 여러 개를 파일 하나에, 필드 이름·타입 유지 | 레이어 `emd`, `stations` |
| Shapefile(zip) | 여전히 가장 널리 쓰임(구버전 GIS·공공 업무) | 필드 이름 10자 제한 → `near_stn`·`near_dist`·`coord_fix`로 줄이고 README에 대응표. `.cpg`에 UTF-8 |
| CSV | 엑셀·통계 도구 사용자용 | 도형 대신 점 좌표(법정동 대표점, 역 위치). UTF-8 BOM(엑셀 한글) |
| GeoJSON | 이미 `data/processed/`에 있음 | 복사하지 않고 원본으로 링크(저장소 5.8MB 중복 방지) |

- 날짜는 포맷마다 타입이 달라지지 않게 `YYYY-MM-DD` 문자열로, 참·거짓은 0/1 정수로 통일
- 파일은 `docs/downloads/`에 두어 GitHub Pages에서 바로 내려받게 한다
- `run.py`는 검증을 통과했을 때만 내보낸다

## 확인 (실제 실행)

- 각 파일을 다시 읽어 원본과 건수·필드 값을 대조(다르면 멈춤): 법정동 467, 역 389 모두 통과
- Shapefile zip 안에 `.cpg`(UTF-8)·`.prj` 있음, 한글 정상(`종로구 청운동`, 최근접 `경복궁` 1,502m), EPSG:4326
- GeoPackage: 레이어 2개 EPSG:4326, `bjd_cd`는 TEXT
- 크기: GPKG 3.24MB, Shapefile 1.47MB + 0.02MB, CSV 0.06MB + 0.04MB
