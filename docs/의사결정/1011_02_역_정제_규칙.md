이용 조건은 공개 전에 각 데이터 페이지에서 확인해 README에 적는다(아직 미확인).

## 결정

1. **이름 정규화**: 괄호 부기와 끝의 `역`을 뗀다(`이촌(국립중앙박물관)` → `이촌`, `역곡역` → `역곡`). 두 글자 이름은 `역`을 떼지 않는다
2. **좌표 보정**: 같은 정규화 이름의 서울시 역사마스터 좌표와 500m 넘게(5km 이하) 차이 나면 서울시 좌표로 바꾸고 `outputs/station_fixes.csv`에 남긴다
3. **역 통합**: 같은 정규화 이름이고 500m 안이면 한 역으로 합친다. 좌표는 노선별 행의 가운데, 노선 목록은 `lines`에 보존
4. **기준일**: `1900-01-00` 같은 2000년 이전 값과 빈 값은 결측으로 두고, 역마다 가장 최근 행 기준일을 `ref_date`로
5. **GTX-A는 넣지 않는다**: 기준 출처에 없다. 서울시 역사마스터에는 10개 역이 있지만, 서울 안 GTX 역(연신내·서울·삼성·수서)은 기존 역과 같은 자리라 접근성 지표에 주는 영향이 작다고 보고 한계에 적는다

## 근거

- 4호선 `이촌` 원본 좌표는 `신용산`과 14m, 5호선 `마곡`은 `발산`과 7m 떨어져 있었다. 실제로는 1km 안팎 떨어진 역이다. 서울시 좌표는 각 역 주소(서빙고로 지하83, 공항대로 지하163)와 맞는다
- 두 출처 차이: 같은 이름 짝 806개 중 중앙값 18.7m, 90%가 76.7m 이내. 출입구·승강장 위치 차이 수준이라 500m를 넘는 경우만 오류로 본다
- `신촌`(2호선)과 `신촌`(경의중앙선)은 701m 떨어진 다른 역이다. 이름만으로 합치지 않고 거리 조건을 둔 이유

## 결과 (실제 실행)

- 원본 1,099행 → 역 943개
- 좌표 보정 5행: `이촌`(4호선, 890m), `마곡`(5호선, 1,095m), `인천공항2터미널`(1,133m), `야목`(520m), `청산`(1,552m). 뒤의 3개는 서울 밖이라 분석 범위(서울 + 완충)에 들어오는지 다음 단계에서 확인
- `이촌`은 4호선·경원선 2개 노선이 한 역으로 합쳐짐, `신촌`은 2개 역으로 남음

## 바꾸는 조건

- 서울시 역사마스터 쪽 좌표가 틀린 사례가 나오면 2번 규칙을 "두 출처가 다르면 표시만 하고 사람이 판단"으로 바꾼다
- 200～500m 차이(`청계산입구` 204m, `미사` 253m, `동구릉` 260m 등)는 지금은 그대로 두고, 검증 리포트에 경고로만 남긴다
