## 법정동 경계: 수집 방법

| 안 | 장점 | 단점 |
|---|---|---|
| VWorld 데이터 API(`req/data`) | 빌라 프로젝트에서 써 본 방식 | VWorld 전용 형식 |
| **VWorld WFS(`req/wfs`, OGC WFS 1.1.0) (채택)** | OGC 표준 요청(GetCapabilities·GetFeature·OGC Filter). 서울 467개를 한 번에 받음 | Filter XML을 직접 써야 함 |
| 다른 프로젝트에서 받은 경계 파일 | 바로 씀 | 원 출처 확인 불가 → 쓰지 않음 |

- 요청: `TYPENAME=lt_c_ademd_info`, `SRSNAME=EPSG:4326`, `OUTPUT=application/json`, OGC Filter `emd_cd PropertyIsLike '11*'`
- 응답의 `emd_cd`는 8자리 → 끝에 `00`을 붙여 10자리 법정동코드로 맞춘다

## 결과 (실제 실행)

- 받은 경계 467개(구 25개), 응답 `numberMatched`와 같음, 코드 중복 0
- 법정동코드 표의 서울 읍면동 단위(리 없음) 467개와 **코드 단위로 전부 일치**(경계에만 있는 코드 0, 표에만 있는 코드 0)
- 도형: 모두 MultiPolygon, 유효하지 않은 도형 0, 빈 도형 0
- 면적 합계(EPSG:5179) 605.3㎢ — 서울시 면적 약 605㎢와 맞음. 가장 작은 동 0.011㎢, 가장 큰 동 18.13㎢

## 바꾸는 조건

- VWorld WFS가 막히거나 응답 건수가 코드표와 달라지면, 같은 레이어를 데이터 API로 받고 이 문서에 이유를 적는다
