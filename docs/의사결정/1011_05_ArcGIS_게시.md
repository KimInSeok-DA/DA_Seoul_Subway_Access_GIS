# 1011_05 ArcGIS Online 게시

## 계정

| 안 | 결과 |
|---|---|
| ArcGIS 공개 계정(기존) | Hosted Feature Layer 게시 권한 없음(Esri FAQ) → 불가 |
| ArcGIS Online 체험판(조직) | 체험이 끝나면 게시한 레이어가 사라짐 → 공개 링크가 깨질 위험 |
| **ArcGIS Location Platform 무료 계정 (채택)** | 1인 조직, `publishFeatures` 권한 있음, 기한 없음. 실제 로그인·게시·덮어쓰기 테스트 통과 |

## 업로드 형식

| 안 | 결과(실제 게시해서 확인) |
|---|---|
| GeoJSON | 게시는 됨. 그러나 `bjd_cd`(법정동코드, 문자열)가 **Integer**로, 실수 필드가 Single로 추정됨 |
| **File Geodatabase(zip) (채택)** | `bjd_cd` **String** 유지, 실수 Double. 덮어쓰기 후에도 타입 유지 |

법정동코드는 다른 데이터와 조인하는 키라 문자열이어야 한다. GDAL의 OpenFileGDB 드라이버로 FGDB를 만들고 zip으로 올린다. 처음 GeoJSON으로 게시한 두 레이어(비공개, 웹맵 연결 없음)는 지우고 FGDB로 다시 게시했다.

## 갱신 방식

- 처음: FGDB 항목 업로드 → `publish()`. 이후: `FeatureLayerCollection.manager.overwrite()`로 **같은 항목을 덮어쓴다**. 항목 ID·서비스 URL이 그대로라 이 레이어를 쓰는 Web Map·앱이 깨지지 않는다
- 항목 ID는 `outputs/arcgis_items.json`에 남겨 다음 실행에서 같은 항목을 찾는다(검색 색인은 반영이 늦어 쓰지 않음)
- 덮어쓰기 직후에는 이전 건수가 나올 수 있어(10-11 테스트), 로컬 건수와 같아질 때까지 3초 간격으로 다시 센다. 끝내 다르면 실패로 멈춘다
- `publish.py`는 시작할 때 `validate`를 다시 돌려, 검증을 통과하지 않으면 올리지 않는다
- 항목 정보: 제목, 요약, 설명(지표 정의·기준일·검증·저장소 링크), 태그 9개, 출처(credits), 이용 조건(license)
- 공유 범위는 코드에서 바꾸지 않는다. 공개(Everyone) 전환은 사용자가 한다

## 결과 (실제 실행)

- 게시 후 다시 실행해 덮어쓰기 확인: 두 레이어 모두 같은 항목 ID, 법정동 467건·역 389건
- 서버 값과 로컬 값 전수 대조: ID 일치 467/467, 389/389, 값이 다른 행 0
- 참고: 참·거짓 필드(`in_seoul`, `coord_fixed`)는 FGDB에서 0/1 정수로 올라간다

## 공개 공유 제한과 대안 (추가)

- 웹맵을 만든 뒤 레이어를 "모든 사람(공개)"으로 바꾸려 했으나 선택지가 비활성. 계정 권한(`portal:user:shareToPublic`)과 기관 설정(`canSharePublic: True`)은 정상
- Esri 문서(Feature services > Manage sharing and security): **Location Platform은 Hosted Feature Layer의 Everyone(public) 공유를 지원하지 않음**. 비공개 레이어를 앱에서 쓰려면 범위를 제한한 API 키를 쓰라고 안내
- 웹맵만 공개하면 로그인하지 않은 사람에게 레이어가 보이지 않음(레이어 항목 익명 조회 403 확인) → 웹맵도 비공개로 되돌림. Instant Apps도 같은 이유로 쓰지 않음

| 안 | 판단 |
|---|---|
| ArcGIS JS 앱 + 제한된 API 키 | 가능하지만 브라우저 코드에 키가 노출됨(주소·권한 제한 필요). 필수 아님 → 시간이 남으면 |
| ArcGIS Online 개인 이용(유료) | 공개 공유·Instant Apps 가능. 비용 |
| **캡처 + 저장소 설명, 공개 지도는 GitHub Pages (채택)** | 서류에서 보여 줄 것은 "ArcGIS로 무엇을 했는가"이고 코드·검증·캡처로 충분. 열었는데 빈 지도가 나오는 링크는 넣지 않음 |

캡처 7장은 `docs/images/`, README "결과 화면"에 넣었다.
