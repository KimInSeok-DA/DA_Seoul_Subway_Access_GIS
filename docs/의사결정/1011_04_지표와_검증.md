# 1011_04 지표 계산과 자동 검증

## 지표 계산

| 결정 | 근거 | 대안 |
|---|---|---|
| 거리·면적은 EPSG:5179(m)에서 계산, 결과는 EPSG:4326 | 경위도(도)로는 거리가 위도마다 달라짐 | — |
| 동 대표점은 `representative_point()` | 항상 폴리곤 안. 오목한 동에서 중심점(centroid)은 동 밖으로 나갈 수 있음 | 중심점 |
| 역은 서울 경계 + 5km 안 | 경계 근처 동은 서울 밖 역이 가까울 수 있음. 500m 반경도 서울 밖 역이 서울 안을 덮음 | 서울 안 역만 |
| `n_station`은 역 단위(노선 중복 없음) | 환승역을 노선 수만큼 세면 역이 몰린 정도가 부풀려짐 | 노선 행 단위 |

## 결과 (실제 실행)

- 법정동 467개, 분석 역 389개(서울 안 307, 서울 밖 5km 안 82)
- `near_dist_m`: 중앙값 412m, 최대 2,928m(종로구 평창동, 산지). 최대값이 완충 5km보다 작아서 5km 밖 역을 빼도 결과가 같다
- 가장 가까운 역이 서울 밖 역인 동은 0개(역 이름 기준). 서울 밖 역은 `cover_500m`에만 영향을 준다
- `n_station`: 역이 있는 동 186개, 없는 동 281개. 합계 307 = 서울 안 역 수
- `cover_500m`: 중앙값 64.3%, 0%인 동 26개
- 이촌동은 역 수 0: 이촌역 주소가 용산동5가(서빙고로 지하83)라 실제 소속과 맞음

## 자동 검증 (`src/validate.py`, 21개 검사)

건수·코드(법정동코드 표와 467=467, 집합 일치), 도형·좌표계, 좌표 범위, 역 좌표 겹침, 역 주소의 법정동 대조, 지표 상식, 최신성. 하나라도 실패하면 종료 코드 1, `run.py --publish`는 업로드하지 않는다.

**기준점 검사를 주소로 자동화**: 처음 계획은 위치를 아는 역 몇 개(강남역 → 역삼동 등)를 손으로 정하는 것이었다. 대신 역 도로명주소의 괄호 안 법정동(`(삼성동)`)을 읽어 역 점과 그 동 경계의 거리를 잰다.
- 같은 동 안에 있는지로 보면 247개 중 199개(81%)만 맞음 → 역은 큰길 아래에 있고 큰길이 동 경계인 경우가 많아, 바로 옆 동에 찍히는 것이 정상
- 경계까지 거리로 보니 대조 242쌍 모두 96m 안(99%가 74m 안) → 허용 거리 200m
- `상봉1동`처럼 행정동 이름은 법정동 표에 없어 대조에서 뺀다

**검증이 오류를 잡는지 확인(음성 시험)**: 좌표 보정을 끈 데이터로 돌리면 "이름이 다른 역이 50m 안" 검사가 `마곡↔발산 7m`, `신용산↔이촌 14m`로 실패하고 종료 코드 1을 냈다.

## 독립 재검증 (validate.py와 다른 방법으로 다시 계산)

| 대상 | 방법 | 결과 |
|---|---|---|
| `near_dist_m` | 대표점 × 전체 역의 측지 거리(WGS84 타원체, pyproj Geod) 전수 계산 | 차이 -0.45～1.15m, 최근접 역 이름 불일치 0 |
| `n_station` | shapely `contains` 반복으로 다시 셈 | 불일치 0, 경계선 위에 걸친 역 0 |
| `cover_500m` | 50m 격자 점 표본(15개 동) | 대부분 1%p 안, 최대 3.8%p(격자 점 25개인 작은 동) |
| 면적 | EPSG:5179 면적 vs 타원체 면적 | 차이 0.07% |
| 경계 위상 | 동 경계 합집합 | 겹침 0.0007㎢, 틈 1,105개 합계 3,883㎡(서울 면적의 0.0006%), 틈 안의 역 0 |
| 같은 역 이중 집계 | 이름이 다른데 300m 안인 서울 역 쌍 | **`이수`(7호선)와 `총신대입구`(4·7호선) 128m → 원본 중복 행** |

이중 집계는 1011_02에 중복 행 제거 규칙을 넣어 고쳤다. 같은 오류를 다시 잡도록 "같은 노선의 이름이 다른 역이 300m 안에 없음" 검사를 추가했고, 고치기 전 데이터로 돌려 `이수↔총신대입구 128m`로 실패하는 것을 확인했다. `신용산`↔`용산`(288m)은 노선이 겹치지 않는 실제로 다른 역이라 검사에 걸리지 않는다.

## 바꾸는 조건

- 새 노선·역 이전으로 주소 대조가 200m를 넘으면, 그 역을 먼저 확인한 뒤 원본 오류면 보정, 실제 위치면 허용 거리를 다시 정한다
