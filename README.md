# 서울 법정동별 지하철 접근성 지도

> 진행 중입니다. 아래 수치·링크는 실제 실행 결과가 나오면 채웁니다.

서울 법정동마다 지하철 접근성 지표를 공공데이터로 계산하고, ArcGIS Online에 Feature Layer·Web Map·앱으로 공개하는 개인 프로젝트입니다.

## 지표

| 지표 | 계산 | 의미 |
|---|---|---|
| `near_dist_m` | 동 대표점에서 가장 가까운 역까지 직선거리(m) | 동네에서 역이 얼마나 먼가 |
| `n_station` | 동 경계 안의 역 수(노선 중복 제거) | 역이 몰린 동 |
| `cover_500m` | 역 500m 반경이 동 면적을 덮는 비율(%) | 동의 몇 %가 역세권인가 |

- 거리·면적은 투영 좌표계 EPSG:5179에서 계산하고, 공개 결과는 EPSG:4326으로 냅니다.
- 대표점은 폴리곤 안에 항상 들어가는 `representative_point()`를 씁니다(오목한 동에서는 중심점이 동 밖으로 나갈 수 있음).
- 서울 경계 근처 동은 서울 밖 역이 더 가까울 수 있어, 역은 서울과 주변 완충 범위까지 포함합니다.

## 데이터 출처

| 데이터 | 출처 | 기준일 | 이용 조건 |
|---|---|---|---|
| 지하철역 좌표 | 공공데이터포털 전국도시철도역사정보 표준데이터 | 2026-06-30 | 확인 예정 |
| 법정동 경계 | VWorld 데이터 API | 수집일 기록 예정 | 확인 예정 |

원본 데이터(`data/raw/`)는 저장소에 올리지 않습니다. 위 출처에서 다시 받을 수 있습니다.

## 실행

```
python src/run.py            # 수집 → 정제 → 지표 → 검증
python src/run.py --publish  # 검증을 통과했을 때만 ArcGIS Online 레이어 갱신
```

API 키와 ArcGIS 로그인 정보는 `.env`로 받습니다(`.env.example` 참고).

## 검증

검증이 하나라도 실패하면 업로드하지 않습니다. 결과는 `outputs/validation_report.md`에 남깁니다(작성 예정).

- 건수: 경계 수와 서울 현존 법정동 수 대조, 법정동코드 중복 없음
- 도형: 유효한 폴리곤, 빈 도형 없음, 좌표계 확인
- 범위: 경계·역이 서울 근처 범위 안, 위도·경도 뒤바뀜 없음
- 기준점 대조: 위치를 아는 역이 맞는 동 안에 있는지
- 지표 상식: `cover_500m`이 0～100 범위
